## 🆚 Qu'est-ce que v4 ajoute vs v3 ?

Features pour dépasser Nayax/Vendon :
- 📐 **Planogrammes interactifs drag-drop** (drag des produits dans les colonnes machines)
- 📋 **Picklists auto** pour les tournées de réassort
- 🎫 **Tickets de service** workflow complet (création → assignation → photo → signature)
- 💰 **Encaissements** (vidange caisse, tubes refill, réconciliation cash vs vente)
- ⭐ **Fidélité consommateur** avec programme tampons + niveaux VIP
- 🎟️ **Free Vend &amp; Vouchers** (campagnes marketing, événements)
- 📝 **Sondages consommateurs** sur l'écran de la machine
- 📜 **Audit log** RGPD complet
- 🎨 **Branding white-label** complet (logo, couleurs, sous-domaine)
- 🌐 **Multi-langue** (FR/EN/DE/ES)

## 🎯 Quel fichier ouvrir pour quel cas ?

**Vendre la plateforme** : `05-dashboard-pro-v4.html` (le plus impressionnant)
**Convaincre une équipe terrain** : `06-driver-app.html` (workflow tech)
**Convaincre l'utilisateur final** : `07-consumer-app.html` (fidélité)
**Démo grand public rapide** : `01-demo-simple.html` (sans login)
